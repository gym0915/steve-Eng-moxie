# 英语默写 HTML 模板设计

## 目标

让英语默写技能与语文默写技能共享同一套 A4 视觉语言，但继续输出适合打印的 Word 文档。学生页只出现中文提示和英文书写横线。

## 设计

- 将语文技能的 `assets/template.html` 复制到英语技能后，改成英语默写专用模板。
- 保留 A4 纵向、顶部信息栏、红色章节标记、白底打印页和紧凑网格。
- 标题使用“看中文写英文”，显示总题数；顶部字段使用姓名、班级、日期、得分。
- 模板以 `{{COUNT}}` 和 `{{WORDS}}` 为占位符，生成器从模板读取颜色、列数和打印尺寸，避免 Word 实现与模板漂移。
- 每题仅显示原始中文释义和统一横线；英语答案、音标、词性、编号和栏目标题只用于源数据校验，不进入学生文档。
- 每行五题，按输入顺序横向排列；不足一行时保留空位，不重排。

## 验证

- 自动测试模板契约、输入校验、顺序保持、A4 页面、五列布局、中文提示存在和英语答案缺失。
- 使用用户图片中的 12 个词条生成一次 DOCX。
- 渲染 DOCX 为 PNG，逐页检查字体、间距、边界、顺序和无答案要求。
